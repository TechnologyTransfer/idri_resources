# IDRI Source Code Repository

Centralized repository for storing and managing source code related to the IDRI website and associated web projects.

## Overview

This repository contains development resources, website source files, and project archives organized by year for easier maintenance and version tracking.

## Repository Structure

```text
.
├── 2025/
├── 2026/
└── README.md
```

- `2025/` — Archived or previous project source code
- `2026/` — Current and active development projects

## Included Projects

### IDRI WordPress Website

Source code and custom development resources for the IDRI WordPress website.

### ACET 2026 Web Page

Frontend and related assets for the ACET 2026 web page project.

## Technologies

Projects in this repository may use:

- HTML5
- CSS3
- JavaScript
- PHP
- WordPress
- Bootstrap
- Tailwind CSS
- MySQL

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Open the project directory:

```bash
cd your-repository
```

## Notes

- Projects are organized by year.
- Older projects are preserved for reference and version history.
- Active development is maintained in the latest project folders.
